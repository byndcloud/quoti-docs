# Extensões Pré-Desenvolvidas

O Quoti oferece, através do Marketplace de Extensões, um conjunto de **extensões prontas para uso**, desenvolvidas para acelerar a customização da plataforma.

Essas extensões podem ser instaladas nos ambientes dos clientes e, se necessário, personalizadas conforme as necessidades específicas.

## Verticais Atendidas

Explore algumas das nossas principais verticais com extensões especializadas:

- 📚 **Educacional**  
- 🔐 **Insurance**  
- 📋 **CSM**  
- ⚖️ **Jurídico**  
- 📈 **Marketing**

> Estas extensões são projetadas para oferecer funcionalidades específicas de cada setor, economizando tempo de desenvolvimento e garantindo aderência ao mercado.

Você pode ver exemplos práticos e documentação de cada uma nos nossos materiais dedicados.
