# Autenticação e Autorização

O Quoti oferece um sistema de autenticação e autorização robusto, que garante segurança e flexibilidade no acesso à plataforma.

## Middleware de Autenticação

O sistema built-in pode ser utilizado como **middleware de autenticação** nas APIs desenvolvidas, independentemente de onde estejam hospedadas. Isso proporciona um **controle de acesso integrado e seguro**.

## Métodos de Autenticação

A plataforma suporta diferentes métodos:

- Autenticação com usuário e senha
- Login social com provedores externos
- Métodos avançados de autenticação (ex: 2FA)

## Gestão de Autorização

Permite definir e gerenciar permissões detalhadas para diferentes grupos de usuários.  
Essa abordagem modular assegura que cada perfil acesse apenas o necessário, respeitando as **políticas de segurança e privacidade** da empresa.

## Conclusão

O Quoti integra um sistema de autenticação e autorização avançado, oferecendo **soluções seguras e adaptáveis** para a gestão de identidades e acessos.
