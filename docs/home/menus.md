# Gestão de Menus por Perfil de Usuário

No Quoti, a experiência do usuário é personalizada através da **configuração de menus específicos por perfil**.

## Menus Inteligentes

Com base no grupo ou perfil, o Quoti exibe menus personalizados. Isso melhora:

- Foco do usuário
- Produtividade
- Navegação intuitiva

## Tipos de Destinos de Menu

Cada item de menu pode apontar para:

- **URLs externas**
- **URLs externas via iframe**
- **Páginas internas da plataforma**
- **Extensões personalizadas** (desenvolvidas via código)

## Benefícios

- Organização visual e funcional
- Melhor experiência para diferentes perfis
- Mais controle sobre o que é visível por usuário
